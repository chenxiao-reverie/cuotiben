# 错题本 · cuotiben

> 把带解析的错题和零散知识点摘录，重建成**能直接拿来复习**的模块化 Markdown 错题本。
>
> **你负责做题和贴解析，它负责把解析变成下次能用的东西。**

任何支持 Agent Skills 约定的宿主都能直接装——Claude Code、WorkBuddy、自建 Agent 都行。产出是纯 Markdown，换编辑器、换 Agent、换电脑，文件本身不变。

## 它和普通错题本的区别

普通错题本是**档案**：题目按章节堆好，解析抄全，归档正确就算完成。

这份的及格线不一样——每份文件开头必须回答三个问题：

- 错题压在哪个模块？**带百分比**
- 这批题是不是**同一类病**？
- 下一步**练什么**？

```
| 编号 | 模块 | 核心考点 | 错题数 | 高频错因 |
| 一 | 唯物论 | 物质与运动、实践观 | 1 | 实践的地位与特征记反 |
| 二 | 唯物辩证法 | 联系观、发展观、矛盾观 | 14 | 原理认识，但材料对不上 |

> 3 题里有 2 题（67%）卡在同一处：原理背得没错，但读不出材料在考哪个原理。
> 所以重点不是再背一遍原理，是建立 关键词 → 原理 的条件反射。
```

没有这一段，错题本就是一堆散题。

## 它解决什么问题

| 手工整理 | 本 Skill |
|---|---|
| 题号随手写，追加几次就乱了 | `错题 01…` 一经生成永不改号，新增只往后接 |
| 模块叫「第一章」「其他」「综合」 | 模块名必须是能当检索词用的考点短语 |
| 同一道题在多处重复出现 | 相似题自动合并，重复项进「附录 E」留痕 |
| 解析整段照抄，越抄越厚 | 压缩成判据，只留推导环节 |
| 复习时不知道错在哪 | 7 项固定错因 + 依据，勾选权在你手里 |
| 数字和正文对不上，说不清有多少题 | 总览表逐模块对账，校验脚本兜底 |

## 核心立场

**解析是唯一权威解源。** 它只做整理、归并、压缩、沉淀，不做题。不另起解法、不推翻解析结论。解析确实有错时，标注 `⚠` 报给你，不私自裁决。

**标注权在用户手里。** 错因与掌握度一律输出未勾选的复选框。它只写「错因依据」作为判断线索，不替你判任何一项。框点不动，所以**加粗即选中**——把「原理错配」加粗，它就知道这题错在哪。

**先诊断，再归档。** 归档正确只是及格线，能指出「问题在哪、下一步练什么」才算交付。

**编号是锚点，不是装饰。** 错题号一经生成永不改——纯序号，不含模块信息，重组只是挪位置。知识点号带模块位（`K1-02`），模块一动必重编，所以必须留映射。

**数量守恒。** 输出题数 = 输入 − 重复合并，且总览表逐模块的数字要和对得上。

```
错题本/行测政治理论.md
├── YAML front matter          # 模块数 / 题数 / 知识点数 / 解析缺失数
├── 首屏引用块                  # 来源 / 整理逻辑 / 题量 / 模块 / 日期
├── 目录                       # 只链模块与附录
├── 零、模块总览与错因诊断       # 总览表 + 错因分布 + 一句话诊断
├── 模块一 唯物论：物质 · 运动 · 实践
│   ├── 1.1 知识点总结          # ① ② 分块，每块一个 K 号
│   └── 1.2 错题                # 每张卡以「错题 01｜标题」开头
├── 模块二 唯物辩证法
├── 附录 A 易混概念对比表        # 可选，有内容才出
├── 附录 B 金句 → 哲理速查       # 可选，仅文科
├── 附录 C 二刷计划             # 可选，需要已标注错因
├── 附录 D 通用方法索引          # 可选，方法在 ≥2 题出现
└── 附录 E 整理留痕             # 必选，去重 / 待归类 / 解析缺失 / 待确认
```

### 一张错题卡

> #### 错题 01｜马克思主义实践观（正确项辨析）
>
> **考点**　K1-02
>
> **题干**　关于马克思主义实践观，下列说法正确的是：
>
> | 选项 | 内容 | 判定 |
> | :---: | --- | :---: |
> | A | 正确发挥主观能动性是实践的根本途径 | ❌ 主客颠倒 |
> | B | 实践的过程就是对于结果的检验和评价 | ❌ 以偏概全 |
> | C | 实践是人类生存和发展最基本的活动 | ✅ |
> | D | 实践是一种无目的适应环境的本能活动 | ❌ 动物行为 |
>
> **答案：C**（我选 A）
>
> **一句结论**：凡是把「实践」和「主观能动性」顺序写反的选项，一律错。

**选项按题型分流**：要逐字判真假的（行测 / 政治 / 英语）用三列辨析表，判定列必须写理由；只看数值的（数学 / 理化）每项一行带 `A.` 标号。

**「一句结论」是这张卡的灵魂。** 它必须能背下来——「两次是辩证法，一次是诡辩论」这种东西，只有放在卡末尾才记得住。写「要认真审题」的，等于没写。

### 标注：加粗即选中

```markdown
- **错因**：☐ 原理错配　☑ **概念混淆**　☐ 表述颠倒　☐ 正确但无关　☐ 记忆偏差　☐ 审题偏差　☐ 蒙对未掌握
- **掌握度**：☐ 待复习　☐ **在练**　☐ 已掌握
```

框点不动，所以加粗就是勾。`☑` 和加粗都认，`☐` 留着不删也行。追加时它会把加粗项算进错因分布——漏读等于你的标注白做。

**为什么没做成可点的。** Markdown 的任务列表要求每项独占一行才能点：七项错因七行，加掌握度三行，一张卡光勾选框就吃掉 10 行。收成一行后，一张卡省下的十行够再放两道题。真要逐项点，说一声切成竖排 `- [ ]`，代价是文件长度翻倍，两种写法不能混用。

## 体量变大之后

切分方案不是一次定终身的。题攒到一定量，当初合理的切分会变成负担。它会在校验时打出「结构健康度」，超阈值就提示，但**从不擅自动手**。

| 信号 | 阈值 | 为什么是问题 |
|---|---|---|
| 模块过多 | > 12 个 | 目录要滚两屏，找模块比找题还慢 |
| 单模块过重 | > 20 题 | 跳到锚点后还要长距离滚动 |
| 待归类积压 | > 5 条 | 附录 E 堆着，说明分类体系有洞 |
| 模块过碎 | 无题模块 ≥ 3 个 | 每类只有一道，形不成组 |

要动结构时，它先给提案（诊断 / 方案 / K 号映射 / 待确认），**你点头才执行**。手段按代价从低到高：改名 → 换归属 → 并模块 → 拆模块 → 加层级。

执行时守三条：**错题号永不改**（重组只挪位置）、**K 号必改必留映射**、**用户标注原样搬走**（动手前后各数一次，对不上就停）。被合并的模块序号**留空不回收**——否则旧笔记里的「模块五」会指向另一个东西。

## 安装

只要宿主支持 Agent Skills（`SKILL.md` + YAML front matter 那套约定），把整个目录放进它的 skills 路径就行。没有插件依赖、没有编译步骤：

```bash
# 先把 SKILLS_DIR 换成本机对应的 skills 目录，见下表
git clone https://github.com/chenxiao-reverie/cuotiben.git "$SKILLS_DIR/cuotiben"
```

| 宿主 | 用户级 | 项目级 |
|---|---|---|
| Claude Code | `~/.claude/skills/cuotiben` | `<repo>/.claude/skills/cuotiben` |
| WorkBuddy | `~/.workbuddy/skills/cuotiben` | `<repo>/.workbuddy/skills/cuotiben` |
| 其他宿主 | 放进它的 skills 扫描目录，具体路径以文档为准 | 同左 |

- **目录名就叫 `cuotiben`**，和 `SKILL.md` 里 front matter 的 `name` 保持一致
- **入口是 `SKILL.md`**，宿主按 `description` 判断何时加载，那段触发词别删
- **零第三方依赖**，唯一的代码是 `scripts/check_notebook.py`，只用 Python 3.9+ 标准库

宿主不支持 Agent Skills 也能用：把 `SKILL.md` 当规范文档喂给它，`examples/` 当范例，校验脚本单独跑——产出是纯 Markdown，不绑定平台。

## 使用方式

不需要记命令，说人话就行：

| 你说 | 它做什么 |
|---|---|
| 贴一批带解析的错题 | 生成新错题本，按学科切模块 |
| 「又攒了一批，追加进去」 | 先读旧文件，接编号往后排，出追加补丁 |
| 「先看看模块怎么分」 | 只出模块地图，等你确认再出全文 |
| 「只要整理结果，别存文件」 | 仅在对话里输出，不落盘 |
| 「重排结构 / 模块分得不对」 | 先出重构提案，你点头才动手 |

处理流程：

```
贴入错题 + 解析
   ↓  拆条，相似题合并
   ↓  定模块骨架（有章节标注用标注，否则按考纲切）
   ↓  写知识点块（① ② 分块，每块一个 K 号，带关键词触发）
   ↓  写错题卡（选项分流 / 易错点 / 一句结论）
   ↓  组装：总览表 + 错因分布 + 一句话诊断
   ↓  跑结构校验，报错就改到通过
交付
```

## 规范速查

### 编号

| 对象 | 格式 | 例子 |
|---|---|---|
| 模块 | `模块<中文序号> <名称>` | `模块二 唯物辩证法` |
| 错题 | `错题 <两位序号>｜<标题>` | `错题 01` |
| 知识点 | `K<模块序号>-<两位序号>` | `K2-03` |

错题号**全局连续**，一科一份文件从 01 排到底，不按模块重置——这样「错题 13」永远指同一道题。

### 错因：每科 7 项，顺序固定，内容可换

| 组 | 用于 | 7 项 |
|---|---|---|
| 文科组 | 行测 / 公考 / 政治 / 教资 / 法考 / 考研政治 | 原理错配 · 概念混淆 · 表述颠倒 · 正确但无关 · 记忆偏差 · 审题偏差 · 蒙对未掌握 |
| 理科组 | 数学 / 物理 / 化学 | 概念不清 · 计算失误 · 审题偏差 · 思路断链 · 记忆混淆 · 时间不足 · 蒙对未掌握 |
| 语言组 | 英语 | 词义不明 · 语法混淆 · 搭配错误 · 长难句误读 · 语义转折漏看 · 时间不足 · 蒙对未掌握 |

项数固定 7、顺序固定，因为统计靠位置对齐。行测那套是从实际病灶倒推的——「原理乱配」和「正确但无关」是两大主坑，理科那套里没有对应项。

### 附录触发条件

| 附录 | 什么时候出 |
|---|---|
| A 易混概念对比表 | 模块内 ≥2 组易混概念 |
| B 金句 → 哲理速查 | 仅文科、政治类 |
| C 二刷计划 | ≥3 题已标注错因 |
| D 通用方法索引 | 同一方法在 ≥2 题出现 |
| E 整理留痕 | 必选 |

没内容就连标题都不写，不要留空章节占位。

## 结构校验

写完必须跑，通过才算交付：

```bash
python3 scripts/check_notebook.py 错题本/高中数学.md
```

```
校验对象: 高中数学.md
  模块 2 / 错题 3 / 知识点 3
  复选框写法: 单行 ☐

✓ 结构校验通过

结构健康度:
  模块 2 个（提示阈值 12） · 错题 3 道（提示阈值 120）
  最重模块 模块二 数列 2 题（提示阈值 20）
  ✓ 结构轻量，无需重构
```

出错时直接指到具体位置：

```
✗ 发现 3 个错误:
  - 总览表写模块二有 3 题，正文实际 2 题
  - 错因分布写「概念不清 2」，卡片里实际标了 0 处
  - 错因分布写「未标注 1」，实际 3 题没有任何标注
```

覆盖十项：front matter 完整、**首屏统计与 front matter 一致**、必选章节齐全、模块序号与错题号连续、K 号模块位正确、**总览表逐模块对账**、**错因分布与实际标注对账**、每题字段齐全、复选框数量与写法统一、选项形态合法。

最有价值的是前两个加粗项：现有工具最多校到「总数对不对」，这里能校到「每个模块分到几题」「每个错因标了几次」。重排或追加时漏题、统计写错，会当场暴露。

退出码 `0` 通过（可能带警告），`1` 有错误，可以直接接进 CI 或 git hook。

## 可选开关

| 开关 | 触发方式 | 效果 |
|---|---|---|
| **补全模式** | 「解析缺的帮我补一下」 | 仅对解析缺失题补写，整段用 `>` 包裹并前置 `⚠ AI 补写，非原解析` |
| **大纲模式** | 「给我一份大纲，方便转思维导图」 | 额外输出 `模块 → 知识点块 → 题数 → 错因分布` 缩进大纲 |
| **可点击竖排** | 「预览里要能逐项点」 | 单行 `☐` 改成 `- [ ]`，每项一行可点；每题多占 10 行 |

补全模式有硬限制：原解析存在时，任何情况下都不许补写或改写。

## 支持的学科

内置 12 套板块模板与三组错因，见 [references/taxonomy.md](./references/taxonomy.md)：

| 类别 | 学科 | 选项形态 | 错因组 |
|---|---|---|---|
| 高中 | 数学、物理、化学 | 列表 | 理科组 |
| 高中 | 英语 | 辨析表 | 语言组 |
| 公考 | 行测、申论、政治理论 | 辨析表 | 文科组 |
| 职业资格 | 银行从业、教师资格证、法律职业资格 | 辨析表 | 文科组 |
| 考研 / 财会 | 考研政治、CPA | 辨析表 | 文科组 |

表里没有的学科也能用：它会翻原文里出现频率最高的方法名和概念名，聚成 3–8 组，并在对话里注明「本学科模块体系为按内容推断，非官方考纲」。错因枚举也可自拟 7 项——写进第一张卡后，校验器以它为准对账。

## 它不做什么

- ❌ 不替你做题。解析是唯一解源，不会另起一套解法
- ❌ 不猜错因。七项全留空，宁可整列显示「待标注」
- ❌ 不美化题干。原样照录，残缺处写 `[原文缺失: 缺什么]`
- ❌ 不私自裁决解析错误。照抄原结论 + 标 `⚠` + 写疑点，全进附录 E
- ❌ 不丢信息。合并的重复项、待归类条目、缺失字段，全部在附录 E 列出
- ❌ 不擅自重构。结构再烂也先出提案，你点头才动手

**预期管理**：它产出的是「可复习的骨架」，不是「读完就能考高分」。错因要你自己标，掌握度要你自己评，第二次追加时它会根据你标的结果重算错因分布——这部分它不代劳。
