# 错题本 · cuotiben

> 把带解析的错题和零散知识点摘录，重建成一份可长期追加、结构稳定的 Markdown 错题本知识库。
>
> **你负责做题和贴解析，它负责把解析变成能反复翻的东西。**

## 它解决什么问题

错题本的真实难点从来不是「记下来」，而是**三个月后还找得到、还看得懂、还能接着往下加**。

手写和随手记的错题本通常死在同一个地方：题号越加越乱、模块越堆越糊、同一道题重复记三遍、解析抄了八百字但复习时只想看那两句关键判断。

这个 Skill 把「整理」这件事拆成一套有约束的流水线：编号只增不改、模块可检索、解析只压缩不重写、错因留给你自己勾。

| 手工整理 | 本 Skill |
|---|---|
| 题号随手写，追加几次就乱了 | `Q-01…` 一经生成永不改号，新增只往后接 |
| 模块叫「第一章」「其他」「综合」 | 模块名必须是能当检索词用的考点名词短语 |
| 同一道题在多处重复出现 | 相似题自动合并，重复项清单留痕可查 |
| 解析整段照抄，越抄越厚 | 压缩到 ≤5 步，只留推导环节，删解释性废话 |
| 复习时不知道错在哪 | 7 项固定错因 + 依据，勾选权在你手里 |
| 数字和正文对不上，自己都说不清有多少题 | 结构校验脚本兜底，数量守恒算给你看 |

## 核心立场

这四条不是风格偏好，是整个 Skill 的硬边界。

**解析是唯一权威解源。** 它只做整理、归并、压缩、沉淀，不做题。不另起解法、不推翻解析结论、不「顺手纠正」解析。解析确实有错时，标注 `⚠` 报给你，不私自裁决。

**标注权在用户手里。** 错因 7 项、掌握度 3 档，一律输出未勾选的复选框。它只写「错因依据」作为判断线索——引用解析里的哪句话、哪个步骤暴露了问题——但不替你判任何一项。框点不动，所以**加粗即选中**：把「计算失误」加粗，它就知道这题错在哪。

**编号是锚点，不是装饰。** 追加时先读旧文件，抽出现有模块 ID、各模块最大 Q/K 号、统计数字，新条目一律接在末尾往后排。**Q 号永不改**——它是纯序号，不含模块信息，重组只是挪位置，没有改号的必要。

**数量守恒。** 输出题数 = 输入题数 − 重复合并数，front matter 的统计数字必须和正文实际数量一致。对不上就是校验失败，不是「大概差不多」。

## 产出长什么样

生成的错题本是一个固定骨架的 Markdown 文件，追加多少次都不会变形：

```
错题本/高中数学.md
├── YAML front matter         # 模块数 / 题数 / 知识点数 / 解析缺失数
├── 错题本变化信息             # 首次还是追加、动了哪些编号、错因分布
├── 目录                       # 三列表格：模块 / 题号范围 / 题数
├── M01 函数与导数             # 标题下一行摘要：> 4 题 · 6 个知识点
│   ├── 知识点                 # 结论一行 + 识别特征/易错点/来源 各一行
│   └── 错题                   # 每张卡之间用 --- 断开
│       └── Q-01 · 一句话说清错在哪
├── M02 数列
├── 通用方法索引               # 只在 ≥2 道题中出现的方法才进
├── M99 待归类                 # 挂不上模块的，写明卡在哪，不许丢
├── 重复项清单
├── 待人工确认                 # ⚠ 解析有问题的题号汇总
├── 解析缺失清单
├── 模块沿革                   # 每次重构的模块增删与 K 号映射，没重构过写「本期无」
└── 整理说明                   # 数量守恒算式，一眼能核对
```

每道错题是一张卡，字段名加粗、错因收在一行（完整示例见 [examples/高中数学.md](./examples/高中数学.md)）：

> **Q-07 · 含参讨论漏掉 a≤0 两种情况**
>
> - **考点**：[K-M02-03]
> - **错因**：☐ 概念不清　☐ 计算失误　☐ 审题偏差　☐ 思路断链　☐ 记忆混淆　☐ 时间不足　☐ 蒙对未掌握
> - **错因依据**：解析第 2 段「需按 a>0、a=0、a<0 三种情况分别讨论」直接指出漏分类；我的答案默认 a>0，未讨论 a≤0
> - **一句话提醒**：动笔前先写出 f'(x) 的判别式，按 Δ 的正负决定要不要分类
> - **掌握度**：☐ 待复习　☐ 在练　☐ 已掌握

**为什么没做成可点的。** Markdown 的任务列表要求每项独占一行才能点：七项错因七行，加上掌握度三行，一张卡光勾选框就吃掉 10 行。收成一行后，一张卡省下的十行够再放两道题——刷题阶段翻得动，比点得爽更要紧。真要在预览里逐项点，说一声切成竖排 `- [ ]`，代价是文件长度翻倍；两种写法不能混在同一个文件里。

### 标注：加粗即选中

```markdown
- **错因**：☐ 概念不清　☑ **计算失误**　☐ 审题偏差　☐ 思路断链　☐ 记忆混淆　☐ 时间不足　☐ 蒙对未掌握
- **掌握度**：☐ 待复习　☐ **在练**　☐ 已掌握
```

框点不动，所以加粗就是勾。`☑` 和加粗都认，`☐` 留着不删也行。追加时它会把加粗项算进错因分布——漏读等于你的标注白做。

### 知识点：结论一行，标注三行

```markdown
- [K-M01-01] 含参单调性必须先定判别式符号
  - 识别特征：f'(x) 是二次型且含参数 a
  - 易错点：默认 a>0 直接开方，漏掉 a=0 与 a<0 两种情形
  - 来源：解析（Q-01）
```

**不写成 `结论 | 识别特征 | 易错点 | 来源` 的单行。** 那样在预览里一折行就是一大段，`识别特征：` 这些标签全埋进正文，扫不出来。也不给知识点建表格——单元格装不下长句，表头一缺就渲染成空表。

### 选项：每个一行

```markdown
- 选项：
  - A. (n-1)·2ⁿ⁺¹+2
  - B. n·2ⁿ⁺¹+2
  - C. (n-1)·2ⁿ⁺²+2
  - D. (n+1)·2ⁿ⁺¹-2
```

四个选项用全角空格挤一行时，预览一折行就分不清哪个是哪个。非选择题整行删掉「选项」，不写「选项：无」。

字段级的写法规范、七项错因的固定顺序、写法一致性规则，都在 [references/card-schema.md](./references/card-schema.md)。

## 安装

只要宿主支持 Agent Skills（`SKILL.md` + YAML front matter 那套约定），把整个目录放进它的 skills 路径就行。没有插件依赖、没有编译步骤、不用改配置：

```bash
# 先把 SKILLS_DIR 换成本机对应的 skills 目录，见下表
git clone https://github.com/chenxiao-reverie/cuotiben.git "$SKILLS_DIR/cuotiben"
```

几个常见宿主的默认位置：

| 宿主 | 用户级 | 项目级 |
|---|---|---|
| Claude Code | `~/.claude/skills/cuotiben` | `<repo>/.claude/skills/cuotiben` |
| WorkBuddy | `~/.workbuddy/skills/cuotiben` | `<repo>/.workbuddy/skills/cuotiben` |
| 其他宿主 | 放进它的 skills 扫描目录，具体路径以文档为准 | 同左 |

四个要点：

- **目录名就叫 `cuotiben`**，和 `SKILL.md` 里 front matter 的 `name` 保持一致，有些宿主靠目录名做索引
- **入口是 `SKILL.md`**。宿主按 front matter 的 `description` 判断何时加载，那段触发词是给检索用的，别删
- **零第三方依赖**。唯一的代码是 `scripts/check_notebook.py`，只用 Python 3.9+ 标准库，`python3` 直接跑
- 宿主若支持上传 zip，打包整个目录上传即可（别把 `.git` 打进去）

宿主不支持 Agent Skills 也能用：把 `SKILL.md` 当规范文档喂给它，`examples/高中数学.md` 当范例，校验脚本单独跑——它的产出物是纯 Markdown，不绑定任何平台。

## 使用方式

不需要记命令，说人话就行：

| 你说 | 它做什么 |
|---|---|
| 贴一批带解析的错题 | 生成新错题本，按学科切模块 |
| 「又攒了一批，追加进去」 | 先读旧文件，接编号往后排，出追加补丁 |
| 「先看看模块怎么分」 | 只出模块地图，等你确认再出全文 |
| 「只要整理结果，别存文件」 | 仅在对话里输出，不落盘 |
| 「重排结构 / 模块分得不对」 | 先出重构提案，你点头才动手 |

多科混在一起发也没关系，它会一科一文件拆开（`错题本/高中数学.md`、`错题本/公考政治理论.md`），不会硬塞进同一个文件。

### 处理流程

```
贴入错题 + 解析
   ↓  拆条编号 Q-01… / K-01…，相似题合并
   ↓  定模块骨架（有章节标注用标注，否则按考纲切）
   ↓  写知识点（每条标来源：摘录 / 解析 / 推断）
   ↓  写错题卡（解析压缩 ≤5 步，错因全留空）
   ↓  组装落盘 + 变化信息段
   ↓  跑结构校验，报错就改到通过
交付
```

## 体量变大之后

切分方案不是一次定终身的。题攒到一定量，当初合理的切分会变成负担。它会在校验时打出「结构健康度」，超阈值就提示，但**从不擅自动手**。

| 信号 | 阈值 | 为什么是问题 |
|---|---|---|
| 模块过多 | > 10 个 | 目录要滚两屏，找模块比找题还慢 |
| 单模块过重 | > 20 题 | 跳到锚点后还要长距离滚动，模块内部没层次 |
| 待归类积压 | > 5 条 | M99 长期堆着，说明分类体系有洞，不是题的问题 |
| 模块过碎 | 单题模块 ≥ 3 个 | 每类只有一道，形不成组 |
| 名称失真 | — | 模块名只覆盖它现在一半的内容 |

要动结构时，它先给提案（诊断 / 方案 / K 号映射 / 待确认），**你点头才执行**。手段按代价从低到高：

| 手段 | 代价 | 什么时候用 |
|---|---|---|
| 改名 | 零 | 名称失真 |
| 换归属 | 低，Q 号不动 | 个别题当初分错 |
| 并模块 | 低，留空号 | 两个碎模块各 1–2 题 |
| 拆模块 | 中，K 号重编 | 单模块 > 20 题 |
| 加层级 | 高，整节重排 | 15–20 题，拆开又太碎 |

执行时守三条：

- **Q 号永不改。** 重组只挪位置，`Q-07` 永远是那道题——这是所有笔记引用、口头讨论不失效的前提
- **K 号必改，必留映射。** K 号带模块前缀（`K-M03-05`），模块一动就得重编，映射表进「模块沿革」，旧号不复用
- **用户标注原样搬走。** 动手前数一遍已勾数量，完成后数一遍，对不上就停下报错

被合并的模块号**留空不回收**——否则旧笔记里的「M07」会指向另一个东西。

各学科的切分建议、五种手段的取舍标准，见 [references/taxonomy.md](./references/taxonomy.md)。

## 文件结构

```
cuotiben/
├── SKILL.md                    # 技能入口：核心立场 + 9 步工作流 + 硬性约束
├── references/
│   ├── taxonomy.md             # 模块切分规则 + 体量演进策略 + 12 个学科的板块清单
│   ├── card-schema.md          # 错题卡 11 字段定义 + 错因枚举 + 勾选框写法
│   └── output-spec.md          # 输出骨架 + 各章节要求 + 重构记录格式
├── scripts/
│   └── check_notebook.py       # 结构校验器 + 结构健康度
└── examples/
    └── 高中数学.md              # 通过校验的完整样例，可直接当模板改
```

| 文件 | 职责 | 何时被读取 |
|---|---|---|
| `SKILL.md` | 技能主文件，定义立场、流程、约束 | 技能加载时必读 |
| `references/taxonomy.md` | 模块数上限、命名规则、体量增长后的五种演进手段、各学科板块清单 | 定模块骨架时 / 重构时 |
| `references/card-schema.md` | 字段表、枚举顺序、勾选框写法与一致性规则、常见错误对照 | 写错题卡时 |
| `references/output-spec.md` | 文件骨架、变化信息格式、模块沿革与 K 号映射格式 | 组装落盘时 |
| `scripts/check_notebook.py` | 9 项结构校验 + 结构健康度，退出码 0/1 | 每次落盘后 |

按需加载是刻意的设计：SKILL.md 只保留判断逻辑，细则摊到 references 里，避免一上来就把几千字灌进上下文。

## 输出规范速查

### front matter

| 字段 | 说明 |
|---|---|
| `title` | `错题本 · <学科>` |
| `updated` | `YYYY-MM-DD` |
| `modules` | 一级模块数，**不含 M99** |
| `questions` | 错题总数 |
| `points` | 知识点总数 |
| `parse_missing` | 解析缺失数 |
| `structure_rev` | 结构版本号，首次生成写 1，每重构一次 +1 |

全部写纯数字，不写「约 10 个」——校验脚本要对它做算术。

### 错因枚举（固定 7 项，顺序不可调）

`概念不清` `计算失误` `审题偏差` `思路断链` `记忆混淆` `时间不足` `蒙对未掌握`

顺序固定是因为统计错因分布时要按位置对齐。不增删、不改名、不调序。默认收成一行、七项全 `☐`；要逐项点击就整份切成竖排 `- [ ]`，同一文件内不许混用。

### 掌握度枚举（固定 3 档）

`待复习` `在练` `已掌握`

### 编号规则

| 类型 | 格式 | 例子 |
|---|---|---|
| 模块 | `M01`–`M16`，`M99` 固定为待归类 | `M03 立体几何` |
| 错题 | `Q-01`…，连续无跳号 | `Q-12` |
| 知识点 | `K-M<模块号>-<序号>` | `K-M05-03` |

知识点 ID 带模块号，所以错题的「考点」字段能直接反查到模块位置——这也是校验脚本会检查「引用的知识点是否有定义」的原因。

## 结构校验

写完必须跑，通过才算交付：

```bash
python3 scripts/check_notebook.py 错题本/高中数学.md
```

正常输出——校验结果加一份结构体检：

```
校验对象: 高中数学.md
  模块 2 / 错题 3 / 知识点 3 / 解析缺失 0
  复选框写法: 单行 ☐

✓ 结构校验通过

结构健康度:
  模块 2 个（提示阈值 10） · 错题 3 道（提示阈值 80）
  最重模块 M02 数列 2 题（提示阈值 20）
  M99 待归类 0 条（提示阈值 5）
  ✓ 结构轻量，无需重构
```

打过标注的文件会多一行 `标注进度: 错因 2/3 题 · 掌握度 1/3 题`——它是在确认你的加粗被读到了，不是在催你标注。

题攒多了会变成这样，只提示不阻断：

```
  ⚠ M01 函数与导数 25 题，建议评估拆模块
  → 说「重排结构」可生成重构提案，不要擅自改
```

出错时直接指到题号和字段：

```
✗ 发现 2 个错误:
  - Q-02 「错因」写法与全文件不一致（全文件主写法：单行 ☐；此处：竖排 - [ ]）
  - Q-02 「掌握度」写法与全文件不一致（全文件主写法：单行 ☐；此处：竖排 - [ ]）
```

覆盖十项：front matter 字段齐全且为数字、模块/题/知识点数与正文一致、Q 号连续无跳号无重复、每题必填字段齐全、复选框数量正确、**全文件复选框写法一致**、选项拆行后每项带标号且不少于两项、考点引用有定义、七个必备章节与变化信息段存在、模块内分组没有误用 `###`。

另外两类「该换写法了」的提醒只警告不阻断：选项挤在一行没拆开、知识点还在用单行竖线写法——旧文件不会因此判失败。

**已勾选的框不算错误。** 你手工标的 `☑`、`[x]`、加粗，都是正常资产，校验器不会把它们当「AI 预勾」拦下来——那条纪律由技能自己守，不该让文件结构承担。反过来，加粗在这个字段里**只有「选中」一个含义**，别拿它标重点，否则统计错因分布时会把强调当成错因。

退出码 `0` 通过（可能带警告），`1` 有错误，可以直接接进 CI 或 git hook。

## 可选开关

默认全关，你提到才开：

| 开关 | 触发方式 | 效果 |
|---|---|---|
| **补全模式** | 「解析缺的帮我补一下」 | 仅对解析缺失题补写，整段用 `>` 包裹并前置 `⚠ AI 补写，非原解析` |
| **大纲模式** | 「给我一份大纲，方便转思维导图」 | 额外输出 `模块 → 考点 → 题数 → 错因分布` 缩进大纲 |
| **可点击竖排** | 「预览里要能逐项点」 | 单行 `☐` 改成 `- [ ]`，每项独占一行才点得动；每题多占 10 行 |

补全模式有硬限制：原解析存在时，任何情况下都不许补写或改写。

## 支持的学科

内置 12 套板块模板，见 [references/taxonomy.md](./references/taxonomy.md)：

| 类别 | 学科 |
|---|---|
| 高中 | 数学、物理、化学、英语 |
| 公考 | 行测、申论、政治理论 |
| 职业资格 | 银行从业、教师资格证、法律职业资格 |
| 考研 / 财会 | 考研政治、CPA |

表里没有的学科也能用：它会翻原文里出现频率最高的方法名和概念名，聚成 3–8 组，并在「整理说明」里注明「本学科模块体系为按内容推断，非官方考纲」，你后面说「模块分得不对」就重排。

## 它不做什么

- ❌ 不替你做题。解析是唯一解源，不会另起一套解法
- ❌ 不猜错因。七项全留空，宁可整列显示「待标注」
- ❌ 不美化题干。原样照录，残缺处写 `[原文缺失: 缺什么]`，不自己补
- ❌ 不私自裁决解析错误。照抄原结论 + 标 `⚠` + 写疑点，全进「待人工确认」
- ❌ 不丢信息。合并的重复项、待归类条目、缺失字段，全部在末尾列出
- ❌ 不擅自重构。结构再烂也先出提案，你点头才动手

**预期管理**：它产出的是「可复习的骨架」，不是「读完就能考高分」。错因要你自己勾，掌握度要你自己评，第二次追加时它会根据你勾的结果重算错因分布——这部分它不代劳。
