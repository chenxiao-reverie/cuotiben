差距的本质：现有产出是**档案**，那份文件是**复习工具**。档案讲归档正确，工具讲下次怎么用。

但那份文件缺三样东西，直接拿来当规范会退步：

1. **无稳定 ID**——正文里靠「对应错题 13 的 D 项」指代，题号一改就断
2. **无标注位**——23 题没有一处能标错因或掌握度，做不了二刷计划的数据基础
3. **无留痕**——去重、解析缺失、解析矛盾都没地方记，只能塞进「附录 C 待补」

## 模块一 唯物论：物质 · 运动 · 实践

> <本模块导语，有话说才写>

### 1.1 知识点总结

**① 物质与运动**

- 运动是物质的**根本属性**和**存在方式**；物质是运动的**载体**。
- 运动是**绝对的、无条件的**；静止是**相对的、有条件的**。

**关键词触发**：只出现"变"或只出现"不动" → 形而上学；"两次踏进同一条河流" → 辩证法。

**② 实践的本质与特征**

| 表述 | 正误 | 说明 |
| --- | :---: | --- |
| 实践是人类生存和发展最基本的活动 | ✅ | 生产实践是最基本的形式 |
| 正确发挥主观能动性是实践的根本途径 | ❌ | 因果倒置 |

### 1.2 错题

#### 错题 01｜马克思主义实践观（正确项辨析）

**考点**　K1-02

**题干**　关于马克思主义实践观，下列说法正确的是：

| 选项 | 内容 | 判定 |
| :---: | --- | :---: |
| A | 正确发挥主观能动性是实践的根本途径 | ❌ 主客颠倒 |
| B | 实践的过程就是对于结果的检验和评价 | ❌ 以偏概全 |
| C | 实践是人类生存和发展最基本的活动 | ✅ |
| D | 实践是一种无目的适应环境的本能活动 | ❌ 动物行为 |

**答案：C**（我选 A）

**⚠️ 易错点**
- **A 项**：正确表述是「**实践**是正确发挥主观能动性的**根本途径**」，A 把主客体位置颠倒。
- **D 项**：出现「无目的」「本能」直接判错——自觉能动性是实践的质的规定性。

**一句结论**：凡是把「实践」和「主观能动性」的顺序写反的选项，一律错。

- **错因**：☐ 原理错配　☐ 概念混淆　☐ 表述颠倒　☐ 正确但无关　☐ 记忆偏差　☐ 审题偏差　☐ 蒙对未掌握
- **错因依据**：解析指出「实践是手段、主观能动性是能力」，A 项把二者颠倒
- **掌握度**：☐ 待复习　☐ 在练　☐ 已掌握

## 三、六项关键决策

### 1. 编号改中文序号

| 对象 | 现在 | v2 |
|---|---|---|
| 模块 | `M01 函数与导数` | `模块一 函数与导数` |
| 错题 | `Q-01` | `错题 01` |
| 知识点 | `K-M01-01` | `K1-01` |
| 总览 | 无 | `零、模块总览与错因诊断`（不占模块序号） |

**稳定性不变**：模块序号和错题号一经生成只增不改。错题号全局连续，不按模块重置——这样「错题 13」永远指同一道题。

**知识点的 K 号用阿拉伯数字**（`K1-01` 的第 1 位是模块序号），因为中文数字当 ID 不好看也不好搜。模块一 → K1，模块二 → K2，以此类推。

### 2. 选项按题型分两种

| 形态 | 适用 | 样子 |
|---|---|---|
| **辨析表** | 行测、公考、文科、英语——选项是「一句话命题」，要逐项判真假 | 三列：选项 / 内容 / 判定 |
| **列表** | 数学、理化——选项是一个值或式子，核对即可 | `- A. …` 每行一个 |

判据：**选项文本要不要逐字读**。要，就用表；只看数值，就用列表。

辨析表的「判定」列必须给理由（`❌ 主客颠倒`），只写 ❌ 不算数——理由才是这道题的价值。

允许在「内容」和「判定」之间插一列（如「原理」「出处」「作者」），对应类题目四列更清楚；判定列固定在最后一列。

### 3. 错因枚举按学科配

每科固定 **7 项、顺序不可调**（校验器靠位置对齐统计），但具体项可换：

| 学科 | 7 项 |
|---|---|
| 行测 / 公考 / 政治 | 原理错配 · 概念混淆 · 表述颠倒 · 正确但无关 · 记忆偏差 · 审题偏差 · 蒙对未掌握 |
| 高中数学 / 理化 | 概念不清 · 计算失误 · 审题偏差 · 思路断链 · 记忆混淆 · 时间不足 · 蒙对未掌握 |

行测这套是从那份文件的实际病灶倒推的：它的诊断说「原理乱配」和「正确但无关」是两个主坑，这两项原 7 项里没有。

### 4. 总览必选，附录可选

- **`零、模块总览与错因诊断` 必选**：没有它，错题本就是一堆散题
- **附录 A/B/C 可选**：有内容才出，没内容连标题都不写
  - A 易混对比：模块内 ≥2 组易混概念时建议出
  - B 金句速查：仅文科类
  - C 二刷计划：≥3 题已标注错因才有分组依据
- **通用方法索引并入附录 D**，不再单列在正文

### 5. 保留现有硬约束

这些不能因为"变好看"就丢：

- 数量守恒：题量 = 输入 − 去重合并，且与总览表逐模块数字对得上
- 错题号只增不改
- 解析是唯一解源，不另起解法
- 用户标注不丢：`☑` / `[x]` / **加粗** 三种标记同等对待
- 去重、待归类、解析缺失、待人工确认——收进一个「附录 E 整理留痕」，不再用六个空章节占正文

### 6. YAML front matter 保留

那份文件没有 front matter，全靠首屏那段引用块。但引用块是给人读的，格式一漂移机器就解析不了。

v2 两者都留：YAML 给校验器读，首屏引用块给人读。**校验器会交叉核对两处的题量、模块数**，对不上就报错——防止改了 YAML 忘了改头。

## 四、校验器改造清单

| 项 | 现在 | v2 |
|---|---|---|
| 模块标题 | `^## M\d+ 名称` | `^## 模块[一二三四五六七八九十]+ 名称` |
| 错题标题 | `^### Q-\d+ · 标题` | `^#### 错题 \d+｜标题` |
| 知识点 | `[K-M01-01]` | `[K1-01]` |
| 总览表 | 无 | **新增：逐模块错题数必须与正文实际一致** |
| 首屏统计 | 无 | **新增：引用块题量/模块数与 YAML 一致** |
| 选项 | 只认列表 | 两种都认：表格（有判定列）/ 列表 |
| 必选章节 | 目录 + 6 个空清单 | 目录 + 零、总览 |
| 附录 | 无 | 可选，出现才校验内部结构 |

总览表与正文的交叉校验是这次最有价值的一条：现有 skill 只校验「总数」，v2 能校验「每个模块分到几题」，重排时漏题会当场暴露。

## 五、迁移

**不自动迁移。** 旧格式（M01/Q-01）的文件继续可用，校验器靠标题格式自动识别是哪一版，不强制转换。

你说的那份《行测政治理论》本来就没有 ID 体系，属于「重建」而非「迁移」——按 v2 重新生成一遍比改省事。

## 八、实施结果

已按方案落地，实施中有五处调整，都比原设想更收敛：

| 项 | 方案 | 实施 |
|---|---|---|
| 变化信息 | 未明确去留 | **删除**。文件不记流水账，追加补丁只发在对话里；错因分布移进「零」 |
| 附录 E | 「收进附录 E」 | 明确为**必选**，四行表格，无异常写「—」。它是「不丢信息」的唯一挂载点 |
| 知识点粒度 | 每条一个 K 号 | 改为**每块一个 K 号**（`**① 主题**　[K1-01]`）。一块 2–6 条，因为「一个知识点」本来就是一组可背诵的命题，不是一句话 |
| 错因组 | 两套（行测 / 数学） | 三套：文科 / 理科 / **语言**。英语的病灶和两边都不重合 |
| 选项表列数 | 三列固定 | 允许中间插一列（原理 / 出处），判定列固定最后 |

### 新增的两条硬校验

1. **总览表逐模块对账**——总览写模块二 14 题，正文实际 12 题就报错
2. **错因分布与实际标注对账**——分布写「原理错配 12」，卡片里只标了 9 处就报错

第 2 条依赖一个设计：错因枚举不写进校验器，而是从第一张卡的「错因」行反推。这样自拟枚举的学科也能对账，校验器不需要认识每个学科。

### 已知代价

- 中文序号的锚点编码难看，所以目录只链模块和附录，不链单题
- 错因枚举跨学科不可比（7 项内容不同），换来的是每科统计更有意义
- 辨析表让文科题卡片变长，但那是这类题唯一能说清「每个选项错在哪」的形态
