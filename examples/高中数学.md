### 错题

### Q-01 · 含参讨论漏掉 a≤0 两种情况

- 考点：[K-M01-01]
- 题干：已知函数 f(x)=x³-3ax+1，求 f(x) 的单调区间。
- 我的答案 / 正确答案：f'(x)=3x²-3a，令 f'(x)>0 得 x>√a，故在 (√a,+∞) 单调递增 / 见解析
- 解析要点：原文「需按 a>0、a=0、a<0 三种情况分别讨论」；「f'(x) 为二次型，判别式符号决定实根个数」
- 错因：
  - [ ] 概念不清
  - [ ] 计算失误
  - [ ] 审题偏差
  - [ ] 思路断链
  - [ ] 记忆混淆
  - [ ] 时间不足
  - [ ] 蒙对未掌握
- 错因依据：解析第 2 段「需按 a>0、a=0、a<0 三种情况分别讨论」直接指出漏分类；我的答案默认 a>0，未讨论 a≤0
- 正解思路：
  1. 求导得 f'(x)=3x²-3a
  2. 按 a 的符号分三类
  3. a>0：f'(x)=0 有两实根，列表判区间符号
  4. a=0：f'(x)=3x²≥0，全程单调递增
  5. a<0：f'(x)>0 恒成立，全程单调递增
- 方法沉淀：参数进了判别式 → 按 Δ>0/=/<0 分三档；参数只在一次项系数上 → 直接移项
- 一句话提醒：动笔前先写出 f'(x) 的判别式，按 Δ 的正负决定要不要分类
- 掌握度：
  - [ ] 待复习
  - [ ] 在练
  - [ ] 已掌握

### Q-02 · 错位相减后项数算错，Sₙ 整体偏移一项

- 考点：[K-M02-01]、[K-M02-02]
- 题干：已知数列 {aₙ} 的通项 aₙ=(2n-1)·2ⁿ，求前 n 项和 Sₙ。
- 我的答案 / 正确答案：Sₙ=2+(2n-3)·2ⁿ⁺¹ / 见解析
- 解析要点：原文「两边同乘公比 2 后错位相减，注意相减后共有 n 项」；「整理得 Sₙ=(2n-3)·2ⁿ⁺¹+6」
- 错因：
  - [ ] 概念不清
  - [ ] 计算失误
  - [ ] 审题偏差
  - [ ] 思路断链
  - [ ] 记忆混淆
  - [ ] 时间不足
  - [ ] 蒙对未掌握
- 错因依据：我的答案常数项为 2 而非 6，代入 n=1 得 2≠a₁=2 恰好成立，掩盖了偏移；解析末段有「回代 n=1 检验」一步
- 正解思路：
  1. 写出 Sₙ=(1·2)+(3·2²)+…+(2n-1)·2ⁿ
  2. 两边乘 2 得 2Sₙ，错位对齐后相减
  3. 中间项构成等比数列，共 n-1 项，用等比求和
  4. 整理得 Sₙ=(2n-3)·2ⁿ⁺¹+6
  5. 回代 n=1：S₁=2=a₁，验证通过
- 方法沉淀：错位相减的收尾动作固定为「整理 → 回代 n=1 → 与 a₁ 比对」
- 一句话提醒：减完先把中间项数数清楚，最后一步必回代 n=1
- 掌握度：
  - [ ] 待复习
  - [ ] 在练
  - [ ] 已掌握
