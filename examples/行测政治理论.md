## 模块一 唯物论：物质 · 运动 · 实践

### 1.1 知识点总结

**① 物质与运动**　[K1-01]

- 运动是物质的**根本属性**和**存在方式**；物质是运动的**载体**。
- 运动是**绝对的、无条件的**；静止是**相对的、有条件的**，是运动的特殊状态。
- 两种错误倾向：只承认静止、否认运动 → **形而上学不变论**；只承认运动、否认静止 → **相对主义 / 诡辩论**。

**关键词触发**：只出现「不动」→ 形而上学；「两次踏进同一条河流」→ 辩证法；「一次也不能」→ 诡辩论。

**② 实践的本质与特征**　[K1-02]

| 表述 | 正误 | 说明 |
| --- | :---: | --- |
| 实践是人类生存和发展最基本的活动 | ✅ | 生产实践是最基本的形式 |
| 实践是正确发挥主观能动性的根本途径 | ✅ | 认识要变为物质力量，只能通过实践 |
| **正确发挥主观能动性**是实践的**根本途径** | ❌ | 因果与主客颠倒 |
| 实践是一种无目的的适应环境的本能活动 | ❌ | 抹掉自觉能动性，那是动物行为 |

- 三大特征：**客观物质性、自觉能动性、社会历史性**。
- 陷阱：蜜蜂筑巢、鸭子戏水**不是实践**——缺乏自觉能动性与社会性。

### 1.2 错题

#### 错题 01｜马克思主义实践观（正确项辨析）

**考点**　K1-02

**题干**　关于马克思主义实践观，下列说法正确的是：

| 选项 | 内容 | 判定 |
| :---: | --- | :---: |
| A | 正确发挥主观能动性是实践的根本途径 | ❌ 主客颠倒 |
| B | 实践的过程就是对于结果的检验和评价 | ❌ 以偏概全 |
| C | 实践是人类生存和发展最基本的活动 | ✅ |
| D | 实践是一种无目的适应环境的本能活动 | ❌ 动物行为 |

**答案：C**（我选 A）

**⚠️ 易错点**
- **A 项**：正确表述是「**实践**是正确发挥主观能动性的**根本途径**」。A 把主客体位置颠倒——实践是手段，主观能动性是能力，「能力是手段的途径」逻辑不通。
- **B 项**：「检验和评价」只是实践**作为真理标准**的功能之一，不能把整个过程等同于一个功能。
- **D 项**：出现「无目的」「本能」直接判错——**自觉能动性是实践的质的规定性**。

**一句结论**：凡是把「实践」和「主观能动性」顺序写反的选项，一律错。

- **错因**：☐ 原理错配　☐ 概念混淆　☐ 表述颠倒　☐ 正确但无关　☐ 记忆偏差　☐ 审题偏差　☐ 蒙对未掌握
- **错因依据**：解析指出「实践是手段、主观能动性是能力」，A 把二者颠倒——背得出原理，但读不出选项把主客换了位
- **掌握度**：☐ 待复习　☐ 在练　☐ 已掌握

## 模块二 唯物辩证法：联系 · 发展 · 矛盾

> 本模块 2 题都是「原理对应」型：四个选项各挂一个原理，材料只对得上一个。先把 2.1 的映射表背下来再看题。

### 2.1 知识点总结

**① 三大规律的关键词**　[K2-01]

| 规律 | 内容 | 关键词 |
| --- | --- | --- |
| **量变质变** | 量变是质变的必要准备，质变是量变的必然结果 | 稳中求进、分步骤、积小胜为大胜、从无到有 |
| **否定之否定** | 两次否定、三个阶段、**螺旋式上升** | 曲折、反复、螺旋、波浪、迂回 |
| **辩证否定观** | 实质是**扬弃**：既克服又保留 | 破立并举、先立后破、批判继承 |

**② 联系 vs 否定之否定**　[K2-02]

- 出现「**之间 / 相互 / 协同 / 相得益彰**」→ **联系类**（普遍性、整体与部分）
- 出现「**自身经历曲折、反复、螺旋上升**」→ **否定之否定**
- 这一对最容易混：都是"多个词并列"，但前者说的是**两个事物的关系**，后者说的是**一个事物的过程**。

**关键词触发**：「稳中求进」→ 量变质变，**不是**否定之否定；「破旧立新但不全盘推翻」→ 扬弃。

### 2.2 错题

#### 错题 02｜碳市场建设的哲学对应（选非）

**考点**　K2-01

**题干**　关于「推进绿色低碳转型和加强全国碳市场建设」总体要求对应的哲学原理，**不正确**的是：

| 选项 | 表述 | 原理 | 判定 |
| :---: | --- | --- | :---: |
| A | 稳中求进、有计划分步骤推进 | 量变质变规律 | ✅ |
| B | 推动传统产业深度转型、培育新质生产力 | 辩证否定观 | ✅ |
| C | 兼顾绿色低碳转型和经济发展需要 | 矛盾的普遍性与特殊性相统一 | ❌ 应为对立统一 |
| D | 为碳达峰碳中和提供支撑 | 实践是认识的目的与归宿 | ✅ |

**答案：C**

**⚠️ 易错点**
- **C 项**：绿色低碳转型与经济发展「看似冲突、本质统一」，这是**矛盾的对立统一（两点论）**；「普遍性与特殊性」讲的是共性与个性，两者完全不同维度。这是「矛盾」这个词引发的误配。
- **B 项为什么对**：传统产业转型不是全盘否定，而是「保留合理部分 + 克服高耗能部分」→ 正是**扬弃**。

**一句结论**：「两个东西打架又统一」→ 对立统一；「一个东西是一般规律的特殊表现」→ 普遍性寓于特殊性。别因为都带「矛盾」就混。

- **错因**：☐ 原理错配　☐ 概念混淆　☐ 表述颠倒　☐ 正确但无关　☐ 记忆偏差　☐ 审题偏差　☐ 蒙对未掌握
- **错因依据**：解析点明 C 把「对立统一」误作「普遍性与特殊性」，同属矛盾范畴，混在同一层
- **掌握度**：☐ 待复习　☐ 在练　☐ 已掌握

#### 错题 03｜培育未来产业的原理对应（选非）

**考点**　K2-01、K2-02

**题干**　下列有关培育未来产业的观点与其体现的哲学原理对应**错误**的是：

| 选项 | 表述 | 原理 | 判定 |
| :---: | --- | --- | :---: |
| A | 既发挥企业主体作用，又政府做好服务 | 两点论与重点论的统一 | ✅ |
| B | 强化产业协同，未来产业同新兴产业、传统产业相得益彰 | 否定之否定规律 | ❌ 应为联系普遍性 |
| C | 从无到有、从有到优的技术突破 | 量变与质变辩证关系 | ✅ |
| D | 综合考虑多种因素，因地制宜、错位发展 | 矛盾的特殊性原理 | ✅ |

**答案：B**

**⚠️ 易错点**——B 说的是「**三个产业之间相互联系、相互促进**」，这是**联系的普遍性**；否定之否定讲的是「**一个事物自身**经历肯定—否定—否定之否定的螺旋上升」，主体和过程都不对。

**一句结论**：看到「之间 / 相互 / 协同」判联系；看到「自身曲折、螺旋上升」才是否定之否定。主体是多个还是一个，是这两者的分水岭。

- **错因**：☐ 原理错配　☐ 概念混淆　☐ 表述颠倒　☐ 正确但无关　☐ 记忆偏差　☐ 审题偏差　☐ 蒙对未掌握
- **错因依据**：解析指出 B 把「三产业相互促进」误挂到否定之否定，主体（多事物 vs 单事物）与过程都不符
- **掌握度**：☐ 待复习　☐ 在练　☐ 已掌握
