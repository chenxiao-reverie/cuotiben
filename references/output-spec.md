## 各章节要求

| 章节 | 要求 |
|---|---|
| front matter | 纯数字，不要写「约」。`modules` 不含 M99 |
| 错题本变化信息 | 必须紧跟 front matter，见下节 |
| 目录 | 三列表格：模块（带锚点）/ 题号范围 / 题数。M99 即使 0 题也列出 |
| 模块章节 | 一级标题用 `##`，紧接一行 `> N 题 · M 个知识点` 摘要，再进入两小节：`### 知识点` 在前，`### 错题` 在后。知识点必须是块状列表（结论一行 + 三个子项），禁止表格，也禁止竖线单行 |
| 题目之间 | 用 `---` 断开，前后各留空行；模块之间同理 |
| 通用方法索引 | 只收解析里明确写出、且在 **≥2 道题**中出现的方法。不足 2 题的留在该题的「方法沉淀」里，不进索引。没有就整节写「本期无」 |
| M99 待归类 | 没有就写「本期无」。不许省略章节——省略了下期会找不到位置 |
| 重复项清单 | 没有就写「本期无」 |
| 待人工确认 | 没有就写「本期无」 |
| 解析缺失清单 | 没有就写「本期无」 |
| 模块沿革 | 只记重构。没重构过整节写「本期无」。格式见下节 |
| 整理说明 | 必须写数量守恒算式，让用户能一眼核对 |

末尾几个清单即使为空也要保留章节，这是文件结构的一部分，缺了会让后续追加找不到挂载点。

## 错题本变化信息

这一段是给用户看的版本流水，不是给你自己看的日志。

首次生成：

```markdown
## 错题本变化信息

- 本次操作：首次生成
- 新增模块：M01~M04，共 4 个
- 新增题号：Q-01 ~ Q-11
- 统计变化：错题 0 → 11，知识点 0 → 34
- 编号变动：无
- 错因分布：待标注（11 题）
```

追加：

```markdown
## 错题本变化信息

- 本次操作：追加 5 题（Q-12 ~ Q-16）
- 新增模块：M05 概率与统计
- 新增题号：Q-12 ~ Q-16
- 统计变化：题 11 → 16，知识点 34 → 45
- 编号变动：无（旧编号未改动）
- 错因分布：概念不清 3 / 审题偏差 1 / 未标注 12（共 16 题）
```

「编号变动」拆成两件事写，不要混为一谈：

- **Q 号**：正常情况下永远写「无」。Q 号是纯序号，重组模块不需要动它。只有用户明确要求合并重复题时才写「Q-11 并入 Q-03」
- **K 号**：模块一动 K 号必动，写清重编了几条，映射表放进「模块沿革」

重构后的变化信息长这样：

```markdown
## 错题本变化信息

- 本次操作：重构（第 2 次），未新增题目
- 新增模块：M13 空间向量与距离
- 合并模块：M09 直线与圆 并入 M07，M09 空号保留
- 统计变化：题 96 → 96，知识点 58 → 58，模块 12 → 12
- 编号变动：Q 号无变动（0 条）；K 号重编 6 条（映射见「模块沿革」）
- 结构版本：1 → 2
- 错因分布：概念不清 4 / 审题偏差 2 / 未标注 90（共 96 题）
```

若本次追加触发了结构阈值，末尾再加一行，把选择权交给用户：

```markdown
- 结构提示：M03 立体几何 已 24 题（阈值 20），建议评估拆分；说「重排结构」可出提案
```

## 模块沿革

只记结构变更，不记内容追加。没重构过的文件整节写「本期无」。

每次重构追加一行表 + 一段 K 号映射：

```markdown
## 模块沿革

| 次 | 日期 | 操作 | 影响 |
|---|---|---|---|
| 1 | 2026-11-17 | 首次生成，M01~M04 | — |
| 2 | 2027-03-08 | M03 拆出 M13；M09 并入 M07 | Q 号 0 变动，K 号重编 6 条 |

### 第 2 次重构 · K 号映射

| 旧 | 新 | 原因 |
|---|---|---|
| K-M03-05 | K-M13-02 | 随「空间向量」拆出 |
| K-M09-01 | K-M07-04 | 随模块并入 |
```

旧号一律不得复用：新模块拿新号，被合并模块的空号留着，否则旧笔记里的「M07」会指向另一个东西。

## 统计口径

错因分布**只统计已选的项**，写在「错题本变化信息」的最后一行。三种标记同等计入：单行的 `☑`、竖排的 `[x]`、以及**被加粗的项**。单行写法里框点不动，加粗是用户唯一的标记手段，追加时漏读就等于他的标注白做。

生成时 AI 不加粗、不勾选，所以首次生成必然是：

```markdown
- 错因分布：待标注（11 题）
```

用户标注后再追加时，重算并写成：

```markdown
- 错因分布：概念不清 4 / 审题偏差 2 / 计算失误 1 / 未标注 4
```

不要为了统计好看去猜错因。宁可整列显示「待标注」。

- 默认路径 `<cwd>/错题本/<学科>.md`

- 写完必须跑 `python3 scripts/check_notebook.py <路径>`，通过才算交付
- 脚本会同时打印结构健康度；出现 ⚠ 时按 §8 的格式补一行「结构提示」，不要私自重排
