# 错题卡字段规范 · v2

每道错题一张卡，以 `#### 错题 <两位序号>｜<一句话标题>` 开头。标题用一句话说清错在哪，不用题干前几个字。「没回代 n=1 验算，系数多算一次」比「第 7 题」有用。

## 字段表

| 字段 | 必填 | 写法 | 说明 |
|---|:---:|---|---|
| 考点 | 是 | `**考点**　K1-02` | 指向已定义的 K 号，多条用顿号分隔 |
| 题干 | 是 | `**题干**　……` | 原样照录，残缺处写 `[原文缺失: 具体缺什么]` |
| 选项 | 否 | 见下节 | 选择题才写；非选择题整段不出现 |
| 答案 | 是 | `**答案：C**（我选 A）` | 括号里是用户原答案，没给就省略括号 |
| 易错点 | 是 | `**⚠️ 易错点**` + 列表 | 逐项拆，一个错项一条 |
| 一句结论 | 是 | `**一句结论**：……` | 能背下来的一句话，≤30 字 |
| 错因 | 是 | `**错因**：☐ …` | 7 项固定枚举，全部未勾选 |
| 错因依据 | 是 | `**错因依据**：……` | 引用解析里的哪句话暴露了错因 |
| 掌握度 | 是 | `**掌握度**：☐ …` | 3 档固定枚举，全部未勾选 |

字段标签一律加粗。十一条破折号长得一样时，加粗的左列能当柱子用。

## 选项写法

### 两种形态，按题型选

| 形态 | 用于 | 判据 |
|---|---|---|
| **辨析表** | 行测、公考、政治、英语——选项是「一句话命题」，要逐字判真假 | 选项文本**要逐字读** |
| **列表** | 数学、理化——选项是一个值或式子 | 选项**只看数值** |

### 辨析表

| 选项 | 内容 | 判定 |
| :---: | --- | :---: |
| A | 正确发挥主观能动性是实践的根本途径 | ❌ 主客颠倒 |
| B | 实践的过程就是对于结果的检验和评价 | ❌ 以偏概全 |
| C | 实践是人类生存和发展最基本的活动 | ✅ |
| D | 实践是一种无目的适应环境的本能活动 | ❌ 动物行为 |

- 第一列是字母，第二列是选项原文，**最后一列必须是判定**
- 判定列要写理由（`❌ 主客颠倒`），只写 ❌ 不算数——理由才是这道题的价值
- 允许在「内容」和「判定」之间插一列（如「原理」「出处」），对应类题目四列更清楚
- 表头三列固定：`| 选项 | 内容 | 判定 |`，插列时插在中间

### 列表

```
- **选项**
  - A. (n-1)·2ⁿ⁺¹+2
  - B. n·2ⁿ⁺¹+2
  - C. (n-1)·2ⁿ⁺²+2
  - D. (n+1)·2ⁿ⁺¹-2
```

每项一行，行首带 `A.` 标号（大写字母 + 半角句点）。不要用全角空格把四个选项挤成一行。

非选择题整段不出现「选项」，不要写「选项：无」。

## 错因枚举

**每科 7 项，顺序固定，不可增删调序**——统计错因分布时按位置对齐。

文件里用哪一套，看第一张卡的「错因」行；追加时沿用同一套，不要中途换。

### 文科组（行测 · 公考 · 政治理论 · 教资 · 法考 · 考研政治）

`原理错配` `概念混淆` `表述颠倒` `正确但无关` `记忆偏差` `审题偏差` `蒙对未掌握`

这套的由来：行测两大病灶是「原理都会背，但材料读出别的原理」和「选项本身没错，跟题干无关」，原 7 项里没有对应项，所以换。

### 理科组（高中数学 · 物理 · 化学）

`概念不清` `计算失误` `审题偏差` `思路断链` `记忆混淆` `时间不足` `蒙对未掌握`

### 语言组（英语）

`词义不明` `语法混淆` `搭配错误` `长难句误读` `语义转折漏看` `时间不足` `蒙对未掌握`

### 自拟

表里没有的学科，按同样原则自拟 7 项：**三个「不会」（知识层）+ 两个「会但错」（执行层）+ 一个「时间」+ 一个「蒙对」**。

自拟的枚举写进第一张卡后，校验器会以它为准核对「错因分布」，所以只要前后一致就能用。

## 掌握度枚举（固定 3 档）

`待复习` `在练` `已掌握`

## 勾选框写法

### 默认：单行紧凑

```
- **错因**：☐ 原理错配　☐ 概念混淆　☐ 表述颠倒　☐ 正确但无关　☐ 记忆偏差　☐ 审题偏差　☐ 蒙对未掌握
- **错因依据**：解析指出「实践是手段、主观能动性是能力」，A 把二者颠倒
- **掌握度**：☐ 待复习　☐ 在练　☐ 已掌握
```

七项一行，用全角空格 `　` 分隔。**全部输出 `☐`，不要预先勾选。** 勾选权在用户手里。

### 标注：加粗即选中

单行写法里框点不动，所以**加粗就代表选中**。不用改 `☐`，把要选的项加粗即可；顺手改成 `☑` 更醒目，两种都认。

```
- **错因**：☐ 原理错配　☑ **概念混淆**　☐ 表述颠倒　☐ 正确但无关　☐ 记忆偏差　☐ 审题偏差　☐ 蒙对未掌握
```

三条纪律：

- **这个字段里加粗只有「选中」一个含义**，不要拿来标重点，否则统计时会把强调当成错因
- **加粗项与 `☑` 项同等计入错因分布**，追加时漏读等于用户的标注白做
- 用户口述「这题是原理错配」时，按他说的加粗——这是他在行使标注权；他没说的一个都不许加粗

### 可选：竖排可点击

用户明确要求「预览里能逐项点」时切换。这是唯一能让复选框真正可点的写法——Markdown 任务列表要求每项独占一行。

```
- **错因**：
  - [ ] 原理错配
  - [ ] 概念混淆
  - [ ] 表述颠倒
  - [ ] 正确但无关
  - [ ] 记忆偏差
  - [ ] 审题偏差
  - [ ] 蒙对未掌握
```

代价是每题多占 10 行。同一文件内不能混用两种写法；竖排用 `[x]` 标记，不要靠加粗。

## 写作要求

### 易错点

不是复述选项，是给出**判据**：

- ❌ 「A 项错误」——等于没说
- ✅ 「A 项：正确表述是『实践是正确发挥主观能动性的根本途径』，A 把主客体位置颠倒」

写不下的才写「A 项：因果倒置，见解析第 2 段」。

### 一句结论

这是整张卡唯一会被反复读的一句，按三个模板写：

| 模板 | 例子 |
|---|---|
| 看到 X → 判断 Y | 看到「之间 / 相互 / 协同」判联系；看到「自身曲折」才是否定之否定 |
| 凡是 Z 一律错 | 凡是把「实践」和「主观能动性」顺序写反的选项，一律错 |
| 两个概念的界碑 | 「两次」是辩证法，「一次」是诡辩论 |

**不写**「要认真审题」「注意区分」——正确但无用，复习时看了没动作。

### 答案

`**答案：C**（我选 A）`。括号里是用户实际选的，用于定位错在哪。用户没给就只写答案，不猜。

## 完整示例

### 选择题（行测类，辨析表）

````markdown
---

#### 错题 01｜马克思主义实践观（正确项辨析）

**考点**　K1-02

**题干**　关于马克思主义实践观，下列说法正确的是：

| 选项 | 内容 | 判定 |
| :---: | --- | :---: |
| A | 正确发挥主观能动性是实践的根本途径 | ❌ 主客颠倒 |
| B | 实践的过程就是对于结果的检验和评价 | ❌ 以偏概全 |
| C | 实践是人类生存和发展最基本的活动 | ✅ |
| D | 实践是一种无目的适应环境的本能活动 | ❌ 动物行为 |

**答案：C**（我选 A）

**⚠️ 易错点**
- **A 项**：正确表述是「**实践**是正确发挥主观能动性的**根本途径**」，A 把主客体位置颠倒。
- **D 项**：出现「无目的」「本能」直接判错——自觉能动性是实践的质的规定性。

**一句结论**：凡是把「实践」和「主观能动性」顺序写反的选项，一律错。

- **错因**：☐ 原理错配　☐ 概念混淆　☐ 表述颠倒　☐ 正确但无关　☐ 记忆偏差　☐ 审题偏差　☐ 蒙对未掌握
- **错因依据**：解析指出「实践是手段、主观能动性是能力」，A 把二者颠倒
- **掌握度**：☐ 待复习　☐ 在练　☐ 已掌握
````

### 解答题（理科，列表无选项）

````markdown
---

#### 错题 02｜含参讨论漏掉 a≤0 两种情况

**考点**　K1-01

**题干**　已知函数 f(x)=x³-3ax+1，求 f(x) 的单调区间。

**答案：见解析**（我选 a>0 单支）

**⚠️ 易错点**
- f'(x) 是二次型，判别式符号决定实根个数；默认 a>0 就把 a=0、a<0 两支漏了。
- a=0 时 f'(x)=3x²≥0，全程单调递增，不是「无解」。

**一句结论**：动笔前先写判别式，按 Δ 的正负决定要不要分类。

- **错因**：☐ 概念不清　☐ 计算失误　☐ 审题偏差　☐ 思路断链　☐ 记忆混淆　☐ 时间不足　☐ 蒙对未掌握
- **错因依据**：解析「需按 a>0、a=0、a<0 三种情况分别讨论」直接指出漏分类
- **掌握度**：☐ 待复习　☐ 在练　☐ 已掌握
````

## 常见错误

| 错误写法 | 问题 | 正确做法 |
|---|---|---|
| 一句结论写成「要认真审题」 | 正确但无动作，复习时用不上 | 写成「看到 X → 判 Y」或「凡是 Z 一律错」 |
| 易错点只写「A 项错误」 | 等于没说，回看时还得重新推 | 给出判据或正确表述 |
| 判定列只写 ❌ 不写理由 | 丢了辨析表唯一的价值 | `❌ 主客颠倒` |
| 错因里预先勾选或加粗 | 剥夺用户判断权，AI 的错因判断准确率有限 | 全 `☐` 不加粗，线索写进「错因依据」 |
| 用加粗标重点 | 这个字段加粗只有一个含义：选中 | 强调换别的写法 |
| 同一文件里两种复选框写法 | 校验直接失败 | 整份统一，要换就整份换 |
| 追加时把加粗读成排版 | 统计偏低，用户标注白做 | 加粗与 ☑ 同权 |
| 非选择题留着「选项：无」 | 无意义占行 | 整段不出现 |
| 错题号按模块重置 | 「错题 03」指向两道题 | 全局连续，一科一份文件从 01 排到底 |
