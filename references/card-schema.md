# 错题卡字段规范

每道错题一张卡，以 `### Q-<两位序号> · <一句话标题>` 开头。标题用一句话说清错在哪，不用题干前几个字。标题写「含参讨论漏代 $a\le 0$」比写「第 7 题」有用。

## 字段表

| 字段 | 必填 | 说明 |
|---|---|---|
| 考点 | 是 | 指向已定义的知识点 ID，如 `[K-M01-03]`，可多条，逗号分隔 |
| 题干 | 是 | 原样照录，含数字、单位、条件。残缺处写 `[原文缺失: 具体缺什么]` |
| 选项 | 否 | 选择题才写，每个选项单独一行带标号；非选择题整行删除，不要留空壳 |
| 我的答案 / 正确答案 | 是 | 用 ` / ` 分隔同一行；用户没给写「未标注」 |
| 解析要点 | 是 | 从原解析抽 1–3 个关键判断句，**保留原措辞**，不改写 |
| 错因 | 是 | 7 项固定枚举，全部未勾选（默认单行 `☐`） |
| 错因依据 | 是 | 引用解析里的哪句话、或哪个步骤暴露了错因，一句话 |
| 正解思路 | 是 | 原解析压缩成 ≤5 步，保留步骤顺序与关键判断 |
| 方法沉淀 | 是 | 该解析体现的通用套路；没有就写「无」 |
| 一句话提醒 | 是 | 下次遇到同类题，第一步该做什么。写动作，不写道理 |
| 掌握度 | 是 | 3 档固定枚举，全部未勾选（默认单行 `☐`） |

**字段名在正文里一律加粗**：`- **考点**：`。十一条破折号长得一模一样时，找「方法沉淀」只能一行行往下看；加粗后左列成柱，眼睛有落点。

## 错因枚举（固定 7 项，顺序不变）

`概念不清` `计算失误` `审题偏差` `思路断链` `记忆混淆` `时间不足` `蒙对未掌握`

顺序固定，因为统计错因分布时要按位置对齐。不要增删、不要改名、不要调序。

## 掌握度枚举（固定 3 档）

`待复习` `在练` `已掌握`

## 选项写法

选择题的选项每个一行，行首带标号：

```
- 选项：
  - A. (n-1)·2ⁿ⁺¹+2
  - B. n·2ⁿ⁺¹+2
  - C. (n-1)·2ⁿ⁺²+2
  - D. (n+1)·2ⁿ⁺¹-2
```

- 标号统一「大写字母 + 半角句点」：`A.`，不要写成 `A、` 或 `(A)`
- 题干末尾留出答题位 `（　）`，和选项对得上
- 不要把选项用全角空格 `　` 挤成一行——预览里一折行，四个选项糊成一片，回看时分不清哪个是哪个
- 不要用表格装选项，单元格会撑得很难看
- 非选择题整行删除「选项」，不要写「选项：无」

## 勾选框写法

### 默认：单行紧凑

```
- **错因**：☐ 概念不清　☐ 计算失误　☐ 审题偏差　☐ 思路断链　☐ 记忆混淆　☐ 时间不足　☐ 蒙对未掌握
- **错因依据**：解析第 2 段「需对 a 分三种情况讨论」直接指出漏分类；我的答案默认 a>0，未讨论 a≤0
- **掌握度**：☐ 待复习　☐ 在练　☐ 已掌握
```

七项一行，用全角空格 `　` 分隔，渲染后不会挤成一团。手工把 `☐` 改成 `☑` 即完成标记。

**所有复选框一律输出 `☐`，不要预先勾选任何一项。** 哪怕依据很明确也只写进「错因依据」，勾选权留给用户。

### 可选：竖排可点击

用户明确要求「预览里能逐项点」时切换。**这是唯一能让复选框真正可点的写法**——Markdown 的任务列表要求每项独占一行，并成一行就只剩符号、点不动。

```
- **错因**：
  - [ ] 概念不清
  - [ ] 计算失误
  - [ ] 审题偏差
  - [ ] 思路断链
  - [ ] 记忆混淆
  - [ ] 时间不足
  - [ ] 蒙对未掌握
- **错因依据**：解析第 2 段「需对 a 分三种情况讨论」直接指出漏分类；我的答案默认 a>0，未讨论 a≤0
- **掌握度**：
  - [ ] 待复习
  - [ ] 在练
  - [ ] 已掌握
```

代价是每题多占 10 行，题量大时文件长度翻倍。同一文件内不要混用两种写法。

### 写法一致性（硬规则）

- 同一份错题本内**只能有一种写法**，混用直接判校验失败
- 判定依据看每张卡的「错因」字段：冒号后直接跟 `☐` → 单行；换行后跟 `- [ ]` → 竖排
- 用户要求切换写法时整份转换，**已勾状态必须保留**：`☑` 转 `[x]`，`[x]` 转 `☑`，转换前后已勾数量必须相等

## 完整示例

下面是一道解答题，没有选项，所以「选项」整行不存在——这是正确写法，不是漏字段。选择题的选项写法见上一节。

````markdown
---

### Q-07 · 含参讨论漏掉 a≤0 两种情况

- **考点**：[K-M02-03]
- **题干**：已知函数 f(x)=x³-3ax+1，求 f(x) 的单调区间。
- **我的答案 / 正确答案**：f'(x)=3x²-3a，令 f'(x)>0 得 x>√a，故在 (√a,+∞) 单调递增 / 见解析
- **解析要点**：原文表述「需按 a>0、a=0、a<0 三种情况分别讨论」；「f'(x) 是二次型，判别式符号决定根的个数」
- **错因**：☐ 概念不清　☐ 计算失误　☐ 审题偏差　☐ 思路断链　☐ 记忆混淆　☐ 时间不足　☐ 蒙对未掌握
- **错因依据**：解析第 2 段「需按 a>0、a=0、a<0 三种情况分别讨论」直接指出漏分类；我的答案默认 a>0，未讨论 a≤0
- **正解思路**：
  1. 求导得 f'(x)=3x²-3a
  2. 按 a 的符号分三类
  3. a>0：f'(x)=0 有两实根，列表判区间符号
  4. a=0：f'(x)=3x²≥0，全程单调递增
  5. a<0：f'(x)>0 恒成立，全程单调递增
- **方法沉淀**：含参题先定位参数在哪一层——进了判别式就要分 Δ>0/=/<0；只在一次项系数上则直接移项
- **一句话提醒**：动笔前先写出 f'(x) 的判别式，按 Δ 的正负决定要不要分类
- **掌握度**：☐ 待复习　☐ 在练　☐ 已掌握
````

## 常见错误

| 错误写法 | 问题 | 正确做法 |
|---|---|---|
| 正解思路多出解析里没有的步骤 | 违反「解析是唯一解源」，等于你自己解题 | 只压缩原文，原文没提的步骤一个字不加 |
| 解析要点做成整段照抄 | 解析 800 字原封不动搬进来，知识库变成解析镜像 | 抽 1–3 个关键判断句，超 150 字必须压缩 |
| 错因预先勾上「概念不清」 | 剥夺用户判断权，且 AI 的错因判断准确率有限 | 七项全空，把线索写进「错因依据」 |
| 一句话提醒写成「要认真审题」 | 正确但无用，复习时看了没动作 | 写成具体动作：「先写出判别式再动笔」 |
| 方法沉淀写「注意分类讨论」 | 泛泛而谈，下次还是不会用 | 写清触发条件与动作：「参数进判别式 → 按 Δ 分三档」 |
| 非选择题留着「选项：无」 | 无意义占行，卡片变臃肿 | 整行删除 |
| 字段标签没加粗 | 十一条破折号长得一样，找某个字段只能逐行扫 | 统一写成 `- **字段**：` |
| 同一文件里一半竖排一半单行 | 校验直接失败，预览里一半能点一半不能 | 跟随旧文件整份统一；要切换就整份转 |
| 转换写法时把 `☑` 转丢了 | 用户几个月的标注归零，且不可恢复 | 转换前后各数一次已勾数量，不等就停 |
| 重构时顺手把 Q 号重排了 | 所有笔记引用、口头讨论全部失效 | Q 号永不改，只挪模块归属 |
| 选项用全角空格挤成一行 | 折行后四项糊成一片，回看分不清哪个是哪个 | 每项单独一行，带 `A.` 标号 |
| 知识点写成 `结论 \| 识别特征 \| 易错点` 单行 | 标签全埋进正文，扫不出来，也没法对齐 | 结论一行 + 三个子项各一行 |
| 给知识点画表格 | 单元格装不下长句，表头一缺就渲染成空表 | 知识点只用列表，不用表格 |
